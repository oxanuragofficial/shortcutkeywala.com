📊 Top 50 Excel Shortcut Keys Every Professional Should Know

January 15, 2024 8 min read 63 shortcuts Beginner to Advanced

Microsoft Excel is the world's most powerful spreadsheet application, used by millions of professionals daily. Mastering Excel keyboard shortcuts can save you hours of work each week and make you a more efficient data analyst. Studies show that using keyboard shortcuts can improve your productivity by up to 40%!

Pro Tip: Practice 5-10 shortcuts per week to build muscle memory. Print this guide and keep it near your monitor for quick reference. Soon, you'll be navigating Excel without touching your mouse!

1. 🚀 Navigation Shortcuts

Ctrl + Arrow Key
Navigate to edge of data region
Ctrl + Home
Go to cell A1 (beginning of worksheet)
Ctrl + End
Go to last used cell
Ctrl + Page Down
Move to next worksheet (right)
Ctrl + Page Up
Move to previous worksheet (left)
Alt + Page Down
Move one screen to the right
Alt + Page Up
Move one screen to the left
Home
Go to beginning of current row
End
Go to end of current row

2. 🖱️ Selection Shortcuts

Ctrl + A
Select entire worksheet (press twice)
Ctrl + Space
Select entire column
Shift + Space
Select entire row
Shift + Arrow Keys
Extend selection by one cell
Ctrl + Shift + Arrow
Extend to last non-blank cell
Ctrl + Shift + Home
Select to beginning of worksheet
Ctrl + Shift + End
Select to last used cell
Ctrl + /
Select array of active cell

3. ✏️ Editing Shortcuts

F2
Edit active cell
Ctrl + C
Copy selected cells
Ctrl + X
Cut selected cells
Ctrl + V
Paste copied/cut cells
Ctrl + Alt + V
Open Paste Special dialog
Ctrl + Z
Undo last action
Ctrl + Y
Redo last action
Delete
Clear cell contents
Ctrl + D
Fill down from cell above
Ctrl + R
Fill right from cell left
Alt + Enter
Start new line in same cell

4. 🔢 Formula Shortcuts

Alt + =
AutoSum selected range
Shift + F3
Open Insert Function dialog
Ctrl + ` (Grave)
Toggle formula view / Show formulas
F4
Cycle absolute/relative references ($A$1 vs A1)
Ctrl + Shift + Enter
Enter array formula
Ctrl + A
Display formula palette / Arguments
Ctrl + Shift + A
Insert argument names in formula
F3
Paste named range into formula

5. 🎨 Formatting Shortcuts

Ctrl + B
Bold text (toggle)
Ctrl + I
Italic text (toggle)
Ctrl + U
Underline text (toggle)
Ctrl + 1
Open Format Cells dialog
Ctrl + Shift + $
Apply Currency format (2 decimals)
Ctrl + Shift + %
Apply Percentage format (no decimals)
Ctrl + Shift + #
Apply Date format (dd-mmm-yy)
Ctrl + Shift + @
Apply Time format (hh:mm AM/PM)
Ctrl + Shift + !
Apply Number format (2 decimals, comma)
Ctrl + 5
Apply/remove Strikethrough

6. 📊 Data & Analysis Shortcuts

Ctrl + Shift + L
Toggle AutoFilter (filters)
Alt + Down Arrow
Open filter dropdown menu
Ctrl + T
Create Table (Convert to table)
Alt + F1
Create embedded chart
F11
Create chart in new worksheet
Ctrl + Q
Quick Analysis options
Ctrl + ; (Semicolon)
Insert current date (static)
Ctrl + Shift + ;
Insert current time (static)
Alt + A + T
Sort ascending
Alt + A + S + D
Sort descending

7. 💾 File Shortcuts

Ctrl + N
New workbook
Ctrl + O
Open workbook
Ctrl + S
Save workbook
F12
Save As
Ctrl + P
Print
Ctrl + W
Close workbook
Ctrl + F4
Close Excel window
Top 10 Must-Know Excel Shortcuts:
  1. Ctrl + C / Ctrl + V - Copy/Paste (saves countless hours)
  2. Ctrl + Z / Ctrl + Y - Undo/Redo (fix mistakes instantly)
  3. Alt + = - AutoSum (fastest way to sum numbers)
  4. Ctrl + Shift + L - Filters (instantly filter your data)
  5. Ctrl + Arrow Keys - Navigation (jump through data quickly)
  6. F2 - Edit Cell (edit without double-clicking)
  7. Ctrl + Space / Shift + Space - Select column/row
  8. Ctrl + 1 - Format Cells (all formatting options)
  9. F4 - Repeat last action or cycle references
  10. Ctrl + ; (Semicolon) - Insert today's date
