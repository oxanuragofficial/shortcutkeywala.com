Windows 11 Shortcuts: 32 Keyboard Shortcuts to Boost Productivity

January 5, 2024 12 min read 32 shortcuts

Windows 11 comes packed with powerful keyboard shortcuts that can dramatically speed up your workflow. Whether you're a power user or casual computer user, mastering these shortcuts will save you hours of time.

Pro Tip: Start with the Windows key shortcuts - they're the most powerful and easy to remember!

1. Windows Key Shortcuts (Most Powerful)

Windows + D
Show/Hide Desktop
Windows + E
Open File Explorer
Windows + L
Lock Computer
Windows + R
Open Run Dialog
Windows + I
Open Settings
Windows + S
Open Search
Windows + A
Open Action Center
Windows + Tab
Task View / Virtual Desktops
Windows + V
Clipboard History
Windows + . (Period)
Open Emoji Panel
Windows + Shift + S
Snipping Tool (Screenshot)
Windows + X
Quick Link Menu

2. Window Management Shortcuts

Alt + Tab
Switch between open apps
Alt + F4
Close current window
Windows + Left Arrow
Snap window to left
Windows + Right Arrow
Snap window to right
Windows + Up Arrow
Maximize window
Windows + Down Arrow
Minimize/Restore window

3. File Explorer Shortcuts

Ctrl + C
Copy
Ctrl + X
Cut
Ctrl + V
Paste
Ctrl + Z
Undo
Ctrl + A
Select All
F2
Rename selected item
Delete
Move to Recycle Bin
Shift + Delete
Permanently delete
Ctrl + Shift + N
New folder
Alt + Enter
Properties

4. Virtual Desktop Shortcuts

Windows + Ctrl + D
Create new virtual desktop
Windows + Ctrl + Left/Right
Switch between desktops
Windows + Ctrl + F4
Close current desktop
Windows + Tab
View all desktops
Quick Summary: The most impactful Windows shortcuts to learn first: Windows+D (Show Desktop), Alt+Tab (Switch Apps), Windows+E (File Explorer), and Windows+Shift+S (Screenshot).
