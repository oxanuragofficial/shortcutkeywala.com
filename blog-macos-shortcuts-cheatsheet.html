macOS Shortcuts Cheatsheet: Master Your Mac with 27 Shortcuts

December 15, 2024 11 min read 27 shortcuts

Mac keyboard shortcuts can transform how you interact with your computer. Learning these essential macOS shortcuts will help you navigate faster, work smarter, and become a true Mac power user.

Pro Tip: On Mac, the Command key (⌘) is your best friend - most shortcuts use it instead of Ctrl like on Windows!

1. Essential Finder & System Shortcuts

⌘ + C
Copy
⌘ + V
Paste
⌘ + X
Cut
⌘ + Z
Undo
⌘ + A
Select All
⌘ + F
Find
⌘ + Space
Spotlight Search
⌘ + Tab
Switch Applications
⌘ + Q
Quit Application
⌘ + W
Close Window
⌘ + H
Hide Application
⌘ + M
Minimize Window

2. Screenshot Shortcuts

⌘ + Shift + 3
Full screen screenshot
⌘ + Shift + 4
Selected area screenshot
⌘ + Shift + 5
Screenshot options menu
⌘ + Shift + 4 + Space
Window screenshot
⌘ + Ctrl + Shift + 3
Full screen to clipboard
⌘ + Ctrl + Shift + 4
Area screenshot to clipboard

3. Finder Navigation Shortcuts

⌘ + N
New Finder window
⌘ + Shift + N
New folder
⌘ + O
Open selected item
⌘ + Delete
Move to Trash
⌘ + Shift + Delete
Empty Trash
⌘ + I
Get Info
⌘ + D
Duplicate
⌘ + Up Arrow
Parent folder
⌘ + Down Arrow
Open item
Quick Summary: The most impactful Mac shortcuts: ⌘+Space (Spotlight), ⌘+Tab (Switch Apps), ⌘+Q (Quit), and ⌘+Shift+4 (Screenshot).
