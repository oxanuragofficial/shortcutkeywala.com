## ✨ Features

* 🔎 Global search with keyboard navigation
* 🖥️ Filter by platform, application, and category
* ↕️ Sort shortcuts by usefulness, name, or category
* ⌨️ Individual keycaps with macOS symbols
* ⭐ Save favorites locally — no account required
* 📋 Copy shortcut combinations instantly
* 🌗 Light and dark themes
* 📚 Practical shortcut guides
* 📱 Responsive design
* ⚡ Lightweight, static website with no backend or login

## 🖥️ Applications

Windows OS · macOS · Ubuntu/Linux · Outlook · Excel · Word · PowerPoint · Figma · VS Code · Web Browsers

## 🛠️ Built With

HTML5 · CSS3 · Vanilla JavaScript

No framework, bundler, or installation required.

## 🚀 Run Locally

```bash
git clone https://github.com/oxanuragofficial/shortcutkeywala1.git
cd shortcutkeywala1
```

Open `index.html` in your browser, or use any static file server.

## 🤝 Contributing

Contributions are welcome!

1. Fork the repository.

2. Update shortcut data in `data.js`.

3. Validate your changes:

   ```bash
   node scripts/validate-data.js
   ```

4. Submit a pull request.

Please ensure shortcuts are accurate and verified.
