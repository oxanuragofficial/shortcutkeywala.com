## 📌 About

**ShortcutKeyWala** is a lightweight, browser-based reference designed to help users discover keyboard shortcuts and improve everyday productivity.

Explore shortcuts across Windows, macOS, and Linux, browse supported applications, save favorites, and quickly find the combinations you need.

No account. No installation. Just shortcuts.

## ✨ Features

| Feature                | Description                                                           |
| ---------------------- | --------------------------------------------------------------------- |
| 🔎 Search              | Quickly find shortcuts with search and keyboard navigation.           |
| 🖥️ Platform filtering | Explore shortcuts by operating system, application, and category.     |
| ↕️ Sorting             | Sort shortcuts by usefulness, name, or category.                      |
| ⌨️ Keycaps             | Read keyboard combinations with individual keycaps and macOS symbols. |
| ⭐ Favorites            | Save your preferred shortcuts locally, without an account.            |
| 📋 Quick copy          | Copy shortcut combinations instantly.                                 |
| 🌗 Themes              | Switch between light and dark themes.                                 |
| 📚 Guides              | Explore practical shortcut guides.                                    |
| 📱 Responsive          | Use the website across desktop and mobile devices.                    |
| ⚡ Lightweight          | Static website with no backend or login requirement.                  |

## 🚀 Getting Started

### Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/oxanuragofficial/shortcutkeywala1.git
```

**2. Open the project directory**

```bash
cd shortcutkeywala1
```

**3. Launch the website**

Open `index.html` in your browser, or use any static file server.

## 🤝 Contributing

Contributions are welcome! Help make ShortcutKeyWala more accurate, useful, and accessible.

### How to Contribute

1. Fork the repository.

2. Create a branch for your changes.

3. Update or add verified shortcut data in `data.js`.

4. Validate your changes:

   ```bash
   node scripts/validate-data.js
   ```

5. Commit your changes and push your branch.

6. Open a Pull Request with a clear description of your contribution.

Please ensure all shortcut combinations are accurate and verified.

Found a bug or have an idea? [Open an issue](https://github.com/oxanuragofficial/shortcutkeywala1/issues).
